# Pesquisa de Satisfação - TudoWeb

Programa em Python que coleta nome, idade e opinião (1-Excelente, 2-Bom,
3-Ruim) de 50 clientes e exibe a quantidade de respostas EXCELENTE e RUIM.

## Como executar
    python pesquisa_tudoweb.py        # 50 entrevistados
    python pesquisa_tudoweb.py 10     # teste com 10 entrevistados

## Recursos usados
- Estrutura de repetição: `for` e `while`
- Estrutura de decisão: `if / elif / else`
- Validação de entradas com `try/except`

## Testes
Executado com 10 entrevistados (ver pasta `prints/`).
Resultado: EXCELENTE = 4, RUIM = 3.
